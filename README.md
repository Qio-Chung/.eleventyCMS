# Eleventy CMS

A simple Eleventy-based content management project.

## Getting Started

1. Install dependencies:
   ```bash
   npm install
   ```
2. Start the development server:
   ```bash
   npm run dev
   ```
3. Build for production:
   ```bash
   npm run build
   ```

## Project Structure

- `src/` — site source files
- `public/` — generated static output
- `package.json` — project scripts and dependencies
